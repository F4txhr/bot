# ShadowChat – Database Schema & tmux Operation Guide

Dokumen ini menjelaskan:

- Schema database (Supabase/PostgreSQL) untuk bot NodeJS.
- Cara menjalankan **bot**, **webhook server Trakteer**, dan **nginx** menggunakan tmux.

> Sesuaikan nama database, user, dan schema dengan environment kamu.  
> Di contoh ini diasumsikan semua tabel dibuat di schema default `public`.

---

## 1. SQL Schema (copy–paste sekali)

Salin blok SQL ini ke Supabase SQL editor atau psql.

```sql
-- =========================
-- 1. USER SETTINGS & STATS
-- =========================

create table if not exists user_settings (
  user_id    bigint primary key,
  lang       text not null default 'id' -- 'id' | 'en'
);

create table if not exists user_stats (
  user_id      bigint primary key,
  total_chats  bigint default 0,
  last_active  timestamptz default now()
);

create table if not exists user_profile (
  user_id       bigint primary key,
  gender        text, -- 'male' | 'female' | 'other'
  target_gender text, -- 'male' | 'female' | 'other' | null (null = any/random)
  updated_at    timestamptz default now()
);

-- =========================
-- 2. PREMIUM & TRUST
-- =========================

create table if not exists premium (
  user_id    bigint primary key,
  expires_at timestamptz not null
);

create table if not exists user_trust (
  user_id             bigint primary key,
  score               int not null default 100,
  total_reports_valid int not null default 0,
  updated_at          timestamptz default now()
);

-- =========================
-- 3. MATCHING & QUEUE
-- =========================

create table if not exists pairs (
  user_id    bigint primary key,
  partner_id bigint not null,
  created_at timestamptz default now()
);

create table if not exists queue_free (
  user_id    bigint primary key,
  joined_at  timestamptz default now()
);

-- =========================
-- 4. BAN & REPORT
-- =========================

create table if not exists banned_users (
  user_id    bigint primary key,
  reason     text,
  created_at timestamptz default now()
);

create table if not exists reports (
  id          bigint generated by default as identity primary key,
  reported_id bigint not null,
  reporter_id bigint not null,
  created_at  timestamptz default now()
);

create table if not exists reported_messages (
  id              bigint generated by default as identity primary key,
  reporter_id     bigint not null,
  partner_id      bigint,
  message_type    text,      -- 'text' | 'photo' | 'sticker' | 'video' | 'document' | 'voice'
  text            text,
  ocr_text        text,
  media_file_id   text,
  media_unique_id text,
  ocr_hash        text,
  text_hash       text,
  created_at      timestamptz default now()
);

create table if not exists banned_media (
  id              bigint generated by default as identity primary key,
  report_id       bigint,
  media_type      text,      -- 'text' | 'photo' | 'sticker' | 'video' | 'document' | 'voice'
  media_unique_id text,
  ocr_hash        text,
  text_hash       text,
  created_at      timestamptz default now()
);

-- Optional foreign key (aktifkan kalau ingin strict)
-- alter table banned_media
--   add constraint fk_banned_media_report
--   foreign key (report_id) references reported_messages(id) on delete set null;

-- =========================
-- 5. PAYMENT SETTINGS & CODES
-- =========================

create table if not exists payment_settings (
  key     text primary key,   -- 'manual' | 'trakteer'
  enabled boolean not null default true
);

create table if not exists payment_codes (
  code       text primary key,
  user_id    bigint not null,
  method     text not null,    -- 'manual' | 'trakteer' | 'any'
  used       boolean not null default false,
  created_at timestamptz default now()
);

create table if not exists payment_sessions (
  user_id   bigint primary key,
  mode      text,              -- 'manual' | null
  updated_at timestamptz default now()
);

create table if not exists payments (
  id          bigint generated by default as identity primary key,
  user_id     bigint not null,
  method      text not null,   -- 'manual' | 'trakteer'
  amount      bigint not null,
  days        int not null,
  status      text not null default 'ok',
  wallet      text,
  code        text,
  tx_datetime timestamptz,
  ocr_text    text,
  created_at  timestamptz default now()
);

-- =========================
-- 6. DISCOUNTS
-- =========================

create table if not exists discount_codes (
  code        text primary key,
  percent     int not null,
  max_uses    int not null default 0,  -- 0 = unlimited
  used        int not null default 0,
  min_amount  bigint not null default 0,
  expire_at   timestamptz,
  created_by  bigint,
  created_at  timestamptz default now(),
  disabled    boolean not null default false
);

create table if not exists user_discounts (
  user_id     bigint not null,
  code        text not null,
  assigned_at timestamptz default now(),
  primary key (user_id, code)
);

-- =========================
-- 7. INDEXES (opsional, untuk kinerja)
-- =========================

create index if not exists idx_premium_expires_at
  on premium (expires_at);

create index if not exists idx_banned_media_type
  on banned_media (media_type);

create index if not exists idx_reported_messages_partner
  on reported_messages (partner_id);

create index if not exists idx_payment_codes_user
  on payment_codes (user_id);

create index if not exists idx_payments_user
  on payments (user_id);

create index if not exists idx_discount_codes_disabled
  on discount_codes (disabled);

create index if not exists idx_user_stats_last_active
  on user_stats (last_active);
```

## 2. Operasi dengan tmux (bot, webhook, nginx)

Di server kamu ada beberapa komponen:

1. **Bot Telegram NodeJS** (`index.js`).
2. **Webhook server Trakteer** (`webhook_server.js`).
3. **nginx** sebagai reverse proxy (biasanya via `systemctl`).

### 2.1. Layout tmux yang disarankan

Gunakan **satu session tmux** bernama `chat` dengan beberapa window:

- Window 1: bot Node.
- Window 2: webhook server.
- Window 3: monitoring/log (nginx, tail log, dsb).

#### 2.1.1. Buat session tmux

```bash
tmux new -s chat
```

Ini membuka session `chat` dan satu window (index 0).

---

### 2.2. Menjalankan bot di tmux

Di dalam window pertama:

```bash
cd /root/bot    # sesuaikan dengan path repo
npm install     # sekali saja kalau belum
npm start
```

- Jika `package.json` mendefinisikan `"start": "node index.js"`, ini akan menjalankan bot.
- Untuk **detach** (keluar sementara dari tmux tanpa mematikan bot):

  - `Ctrl+b`, lalu `d`.

Untuk kembali lagi:

```bash
tmux attach -t chat
```

---

### 2.3. Menjalankan webhook server Trakteer

Buat window kedua di tmux:

- Dari dalam session `chat`:

  - `Ctrl+b`, lalu `c` → window baru.

Di window 1 (atau 2, lihat di status bar tmux):

```bash
cd /root/bot    # sama dengan repo
node webhook_server.js
```

Catatan:

- Jika kamu ingin memudahkan, bisa tambahkan script ke `package.json`:

  ```json
  "scripts": {
    "start": "node index.js",
    "webhook": "node webhook_server.js"
  }
  ```

  Lalu jalankan:

  ```bash
  npm run webhook
  ```

---

### 2.4. Nginx

Biasanya nginx berjalan sebagai service sistem, **bukan langsung di tmux**. Cara umum:

- Cek status:

  ```bash
  systemctl status nginx
  ```

- Restart:

  ```bash
  systemctl restart nginx
  ```

Kalau kamu mau memantau log nginx di tmux:

- Buat window ketiga:

  - `Ctrl+b`, lalu `c`.

- Di window itu:

  ```bash
  tail -f /var/log/nginx/access.log
  # atau
  tail -f /var/log/nginx/error.log
  ```

Jadi layout tmux kamu:

- Window 0: bot (`npm start`).
- Window 1: webhook (`node webhook_server.js` atau `npm run webhook`).
- Window 2: log / monitor (nginx, syslog, dll).

---

### 2.5. Ringkasan perintah tmux yang berguna

**Dari luar tmux:**

- Buat session baru:

  ```bash
  tmux new -s chat
  ```

- Lihat daftar session:

  ```bash
  tmux ls
  ```

- Attach ke session:

  ```bash
  tmux attach -t chat
  ```

- Bunuh session:

  ```bash
  tmux kill-session -t chat
  ```

**Di dalam tmux:**

- Detach: `Ctrl+b`, lalu `d`.
- Window baru: `Ctrl+b`, lalu `c`.
- Pindah window: `Ctrl+b`, lalu `n` (next) atau `p` (previous).
- Daftar window: `Ctrl+b`, lalu `w`.
- Split pane vertikal: `Ctrl+b`, lalu `%`.
- Split pane horizontal: `Ctrl+b`, lalu `"` (tanda petik ganda).
- Pindah antara pane: `Ctrl+b`, lalu panah (← ↑ → ↓).

---

### 2.6. Workflow harian yang praktis

1. Login ke server.
2. `tmux attach -t chat` (jika sudah ada session).  
   Jika belum:

   ```bash
   tmux new -s chat
   cd /root/bot
   npm start                 # window 0: bot
   ```

3. Buat window untuk webhook (sekali saja):

   ```bash
   Ctrl+b, c                 # window 1
   cd /root/bot
   npm run webhook           # atau node webhook_server.js
   ```

4. (Opsional) window untuk log nginx:

   ```bash
   Ctrl+b, c                 # window 2
   tail -f /var/log/nginx/error.log
   ```

5. Setiap kali ingin cek / restart bot:

   - `tmux attach -t chat`.
   - Pindah window: `Ctrl+b, 0` untuk ke bot, `Ctrl+b, 1` ke webhook.
   - Stop: `Ctrl+C`, lalu `npm start` lagi.

6. Setelah pengaturan selesai:

   - Detach: `Ctrl+b, d`.  
     Semua proses di tmux tetap jalan (bot, webhook, tail log).
